# P6 - Research-data and reproducibility reviewer (also assigned the adversarial task T12)

Owns: the schema, determinism, auditability, and the claim of this panel test. Ran T06 and T08.

## Verdict

The data layer is unusually disciplined for a personal instrument: deterministic ids for DOIs, an
append-only collection, a validator, a generated bundle, a generated manifest, and a git history that
shows what changed and why. Three defects break the promises that the documents make. **The abstract is
dropped at promotion**, so the enrichment step spends API calls that are thrown away. **The discourse id
rule is not deterministic**, so the same article can enter twice, which the schema claims cannot happen.
**The policy in `profile.json` is not enforced by any check.** On the audit trail: `lastRun.json` is a
single document that each run replaces, so the history lives only in git, which is acceptable but should
be stated. On the claim of this test, see the separate verdict below; it is not what the panel document
implies.

## Adversarial verdict on the confidence claim (T12)

The panel document states that one round is 200 cells and that the gate needs 197 passes for a Wilson
95% lower bound of 0.95. The arithmetic is right: 197/200 gives 0.957 and 196/200 gives 0.950, so the
"three failures allowed" framing is exact.

The claim is nevertheless weaker than it looks, for three reasons, and the panel document must say so
in the score report rather than in a footnote.

1. **The eight reviewers are one model.** They are not independent samples. The interval assumes
   independent Bernoulli trials; the cells here are correlated by construction, which makes the true
   interval wider than the computed one. The number is a **consistency check**, not a population
   estimate.
2. **The features are not equally independent.** F04, F06 and F23 are judged by the same evidence, so a
   single refusal can cascade across cells and flatter the pooled figure in either direction.
3. **The population is undefined.** "95% confident" of what? There is no sampling frame of researchers
   for a personal instrument for one reader. The honest statement is: "the frozen specification passed
   near-unanimously under this simulated panel, and the residuals are named".

What would falsify the claim: a real reviewer, given the same brief, refusing a feature that the eight
simulated reviewers accepted; or two reviewers of the same discipline disagreeing on the same evidence.
Both are cheap to test with three colleagues and 90 minutes, and I recommend that the panel document
require it before any redesign is called finished.
